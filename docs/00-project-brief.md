# AVRÉN — Project Brief

## 1. Project Identity

**Brand:** AVRÉN  
**Category:** Fashion / Clothing  
**Visual direction:** Elegant, premium, modern, editorial, bold.  
**Primary palette:** Black, white/off-white, signature red accent.

The website is a static-first brand website. It does not require an admin panel, authentication, dashboard, CMS, database, or backend functionality.

The primary goal is to establish AVRÉN as a visually strong fashion brand and present its clothing collections through a cinematic editorial experience.

## 2. Technology

- Nuxt.js
- Vue
- Static content/data
- CSS architecture suitable for maintainable Nuxt components
- Lenis for smooth scrolling
- Vanilla JavaScript/Vue logic for interaction and motion where practical
- GSAP may be used when it produces a more reliable result for complex motion
- Responsive desktop/tablet/mobile experience

Do not introduce unnecessary architecture, state management, backend APIs, authentication, or CMS.

## 3. Reference Direction

The Marcus Vane reference is a **visual and interaction reference**, not content to copy.

Preserve its:
- cinematic dark-mode composition
- oversized condensed typography
- red accent treatment
- editorial spacing
- layered hero composition
- asymmetric grids
- thin separators
- smooth scrolling
- preloader experience
- text reveals
- staggered entrances
- marquee
- liquid/distortion image interaction
- mobile navigation animation
- reduced-motion behavior

Translate those principles into a fashion context.

Do NOT reproduce Marcus Vane's founder/venture narrative or simply replace the name with AVRÉN.

## 4. Brand Principle

The website should feel like a premium fashion campaign first and a product catalog second.

Avoid:
- generic ecommerce templates
- dense marketplace-style grids
- excessive cards
- excessive borders
- excessive red
- over-animated UI
- generic SaaS aesthetics
- dashboard-like interfaces

Prefer:
- large photography
- strong typography
- deliberate whitespace
- editorial composition
- restrained interaction
- high visual contrast
- clear product hierarchy

## 5. Brand Voice

Copy should be concise, confident, modern, and premium.

Avoid exaggerated marketing clichés and excessive promotional language.

Potential brand language direction:
- Defined by Detail.
- Modern Essentials.
- Wear Your Presence.
- Designed with Intention.

These are directional examples, not mandatory final copy.
