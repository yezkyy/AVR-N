# AVRÉN — Antigravity Execution Brief

## Mission

Build the AVRÉN fashion brand website in Nuxt.js.

The website is static-first with no admin, authentication, CMS, database, or backend.

The Marcus Vane reference supplied by the user is the visual/interaction benchmark.

Do not copy its content or identity.

## Core Instruction

Recreate the **visual quality, layout philosophy, UI/UX rhythm, typography scale, image composition, and motion character** of the reference, then translate those principles into a premium fashion brand experience for AVRÉN.

AVRÉN must look like its own brand.

## Required Priorities

### Priority 1 — Visual fidelity
Get these right before adding secondary features:
- hero composition
- typography scale
- spacing
- image positioning
- dark palette
- red accent
- section rhythm
- editorial grid

### Priority 2 — Motion
Implement:
- preloader
- hero letter reveal
- section reveal
- stagger
- marquee
- image hover treatment
- mobile menu animation
- smooth scrolling

Motion must be refined, not excessive.

### Priority 3 — Responsive
Test:
- 360px
- 390px
- 768px
- 1024px
- 1440px
- 1920px+

Do not allow:
- text clipping
- horizontal overflow
- broken hero composition
- unreadable product metadata
- accidental desktop hover behavior on mobile

## Reference Translation Rules

Reference concept:
- founder portrait → fashion model/product campaign imagery
- founder name → AVRÉN brand typography
- ventures → products/collections
- impact statistics → brand/product statements if needed
- voices/testimonials → lookbook/brand philosophy
- contact CTA → collection/brand CTA

Do not retain founder/business-investor semantics.

## Image Generation

If suitable images are unavailable, generate them with Gemini.

Maintain a single coherent art direction:
- premium fashion editorial
- realistic photography
- dramatic but controlled lighting
- dark/neutral palette
- black, white and restrained red accents
- premium textile detail
- modern styling
- sophisticated compositions
- negative space where typography needs to sit

Generate hero and collection assets with consistent visual identity.

## Implementation Sequence

1. Inspect existing Nuxt project.
2. Establish global CSS variables and typography.
3. Build navigation.
4. Build preloader.
5. Build hero.
6. Build marquee.
7. Build featured collection.
8. Build story/philosophy.
9. Build product grid.
10. Build lookbook.
11. Build CTA.
12. Build footer.
13. Add Lenis.
14. Add reveal system.
15. Add image interaction.
16. Add responsive refinements.
17. Test reduced motion.
18. Run final visual and performance review.

## Quality Gate

Before considering the implementation complete, verify:

- The first viewport immediately communicates AVRÉN.
- Hero feels editorial rather than ecommerce-template-like.
- Typography is dominant and intentional.
- Red is an accent, not the entire interface.
- Product photography has visual priority.
- Sections have strong rhythm.
- Animations feel smooth and coordinated.
- Mobile remains premium and usable.
- No unnecessary backend/admin/auth architecture exists.
- Static generation works.

If a technical implementation conflicts with the visual result, prioritize a clean implementation that preserves the intended visual result without introducing unnecessary complexity.
